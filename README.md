# Region platform

The reference platform for a **Region** in the [Polycentric Commonwealth](https://github.com/Polycentric-Commonwealth/foundation): the layer that coordinates shared infrastructure, environment, disaster reserves and appeals among a group of States. Each Region runs its own instance, and existing unions would likely adapt it to their current systems rather than adopt it wholesale.

The Region sees aggregate and project data, never personal records.

## Planned first stage

- Attest the Region's member States, and be attested by the Commonwealth.
- Act as a ledger witness and as a uniqueness operator.
- Aggregate State statistics and publish regional metrics.

The full list of planned modules is in the [platforms plan, section 5](https://github.com/Polycentric-Commonwealth/foundation/blob/main/docs/design/platforms-plan.md#5-region-platform).

## Status

Not started. The first stage is planned in the [platforms plan](https://github.com/Polycentric-Commonwealth/foundation/blob/main/docs/design/platforms-plan.md#10-build-roadmap-and-open-questions). It will use the same stack and shared [foundation](https://github.com/Polycentric-Commonwealth/foundation) library as the [State platform](https://github.com/Polycentric-Commonwealth/platform-state): Go, SQLite or PostgreSQL, and server-rendered HTML ([decision 0004](https://github.com/Polycentric-Commonwealth/foundation/blob/main/decisions/0004-technology-stack.md)).
